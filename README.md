# 💅 Luxury Nails — Beauty Experience

O Luxury Nails é um projeto de site para manicure, pedicure e Nail Designers, com uma proposta visual moderna e sofisticada.

A ideia é criar uma experiência interativa, com animações, elementos 3D e transições suaves durante a navegação, valorizando os serviços e facilitando o contato com as clientes.

## 🚀 Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js
- Lucide React

## ✨ Funcionalidades

- Design responsivo para celular e computador.
- Animações e efeitos visuais em 3D.
- Transições durante a rolagem da página.
- Galeria de trabalhos.
- Apresentação dos serviços.
- Agendamento direto pelo WhatsApp.
- Otimização para mecanismos de busca (SEO).

## 💻 Como executar o projeto

```bash
# Clonar o repositório
git clone https://github.com/CARLOSEMANUEL0112/luxury-nails.git

# Entrar na pasta
cd luxury-nails

# Instalar dependências
npm install

# Iniciar o projeto
npm run dev
```
